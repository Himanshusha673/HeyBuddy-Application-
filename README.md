# 🚀 HeyBuddy

HeyBuddy is a modern, real-time chat application built with **Flutter** and a **Node.js backend**, designed to support both **human-to-human chat** and **AI-powered conversations**.

The project focuses on clean architecture, smooth UX (WhatsApp-like chat behavior), and scalable real-time communication using WebSockets.

---

## ✨ Features

### 💬 Chat
- Real-time one-to-one messaging
- Message status support: **sent, delivered, read**
- Typing indicators
- Online / offline presence
- Last seen status

### 🤖 AI Chat
- Dedicated AI assistant chat
- Instant responses with “thinking” indicator
- Seamless UI experience similar to human chat

### 📱 UI / UX
- WhatsApp-style smooth scrolling
- Smart auto-scroll (no jump when reading old messages)
- Modern chat bubbles
- Responsive layout with keyboard handling

### 🔐 Security & Best Practices
- Environment-based configuration (`.env`)
- Secrets excluded from version control
- Clean Git history and production-ready setup

---

## 🛠️ Tech Stack

### Frontend
- **Flutter**
- **Bloc (State Management)**
- **WebSocket / Socket-based events**
- Clean UI with custom widgets

### Backend
- **Node.js**
- **Express.js**
- **Socket.IO**
- **MongoDB**
- JWT-based authentication
- Scalable event-driven architecture
